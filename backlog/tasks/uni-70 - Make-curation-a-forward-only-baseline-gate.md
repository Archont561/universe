## Description
<!-- SECTION:DESCRIPTION.BEGIN -->
GitHub issue #18 wants curation progress recorded behind a fingerprint, so a package that was
admitted and then fails is a regression rather than an absence. The idea is sound and the
mechanism is real — `alint 0.20.1` ships `baseline`, and `universe lint` exists to extend —
but three of its premises needed correcting:

- It says `universe-kit lint` does not exist. It does: `universe lint` emits `Diagnostic`s
  with `--json`. What it lacks is anything per-package to baseline.
- Its definition of done asks the relock bot to regenerate the baseline. `.github/workflows/
  relock.yml` (`decision-118`) repairs lockfiles and runs no product lint; that step is new
  work, not a reuse.
- It cites a "playtest parity baseline (separate issue on playtest)". House rule 9 forbids
  references to Universe-adjacent repositories, so that comparison has to be restated in
  this repository's own terms or dropped.

`UNI-47` already owns v1 evidence aggregation, so this task's first job is to say what it
adds that `UNI-47` does not.
<!-- SECTION:DESCRIPTION.END -->

## Acceptance Criteria
<!-- AC.BEGIN -->
- [ ] #1 The baseline records a (package × capability) matrix with a fingerprint that covers the rules, not only their results, so a rule change invalidates it.
- [ ] #2 A package that passed and now fails is reported with the package, the capability, and both statuses.
- [ ] #3 A newly admitted package that lacks required metadata fails, naming the package and the missing capability.
- [ ] #4 Updating the baseline requires an explicit flag and records who changed it and why.
- [ ] #5 The relationship to `UNI-47` is recorded: which questions the baseline answers and which stay with evidence review.
<!-- AC.END -->

## Definition of Done
<!-- DOD.BEGIN -->
- [ ] #1 The baseline file is committed and regenerated by a named Pixi task, not by a workflow that was designed for lockfiles.
- [ ] #2 The gate fails on a deliberate regression in a fixture and passes on an unchanged tree.
- [ ] #3 A decision records the mechanism and points at `UNI-47`'s evidence model rather than duplicating it.
<!-- DOD.END -->
