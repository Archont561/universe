## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement consumer repository scaffolding and recipe onboarding (`universe-kit init` and `universe-kit add`, `doc-2`, `decision-1`, `decision-8`):
- `universe-kit init`:
  - Emits `universe.toml`, consumer `pixi.toml` (`channels = ["conda-forge", "https://prefix.dev/archont561/archont561"]` with explicit `channel = "https://prefix.dev/archont561/archont561"` pin on `universe-kit`), `.gitignore`, and `.github/workflows/{ci,publish,upstream-watch}.yml`.
  - Stamps generated workflows with `# @generated by universe-kit <ver> — sha256:<digest>` verified by `universe-kit lint --check-workflows` and updated idempotently by `universe-kit init --sync-workflows`.
  - Enforces strict privilege separation in generated `publish.yml`: unprivileged `plan` + `build-and-audit` jobs (`contents: read`, zero secrets/OIDC), followed by a zero-untrusted-code `publish` job (`environment: release`, `id-token: write`, `pages: write`, `contents: write`) installing `universe-kit` directly from `prefix.dev/archont561/archont561`.
- `universe-kit add <name> [--from-github | --from-pypi | --from-crates]`:
  - Queries upstream metadata, streams source tarball to compute `sha256`, detects SPDX license, and scaffolds `recipes/<name>/recipe.yaml` + `recipes/<name>/package.toml`.
<!-- SECTION:DESCRIPTION:END -->
